GitHub Discussions are open: [github.com/RA-CONSULTING/Aureon-OS/discussions](https://github.com/RA-CONSULTING/Aureon-OS/discussions).

| You are here to… | Start in |
|---|---|

| Propose an idea | [Ideas](https://github.com/RA-CONSULTING/Aureon-OS/discussions/categories/ideas) |

| Report a vulnerability | The private channel in [`SECURITY.md`](../SECURITY.md) |

Announcements are maintainer updates. Polls are for a vote. An older announcement can describe earlier packaging. The release boundary for this checkout is the HOLD in the go-live runbook.

Read [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) before you post. Search existing discussions first. Name the commit you are on, what you read, and what you ran. Keep credentials, customer data, exchange keys, and private evidence out of the thread.
