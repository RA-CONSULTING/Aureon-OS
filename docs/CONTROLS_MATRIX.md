# Controls matrix

This table maps control areas to SOC 2 Trust Services Criteria (TSC) and ISO/IEC 27001:2022 Annex A themes, then to what this repository actually does. It is **aligned with** those themes. It is not an attestation, and no formal audit has been done.

Status meanings:

- **in place** — a real file, setting, or process was checked in this tree or on the GitHub repository and does the job named in the row
- **partial** — something real exists, but a named gap remains
- **planned** — the gap is known and is not yet done in the repository or in GitHub settings

Evidence paths are relative to the repository root. Every **in place** cell cites a file or a setting that was checked.
