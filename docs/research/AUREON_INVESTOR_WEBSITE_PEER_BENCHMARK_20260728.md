# Aureon investor website peer benchmark refresh

Checked: 28 July 2026  
Scope: public information architecture, research-to-commercial narrative,
evidence placement, original visual direction and restrained motion.

## Research boundary

This is a design-pattern record, not a comparative performance claim. It
records only high-level public observations from official sites. Aureon must
not copy competitor copy, code, imagery, CSS, diagrams, screenshots, visual
identity or trade dress.

## Transferable patterns

| Official public source | High-level observed pattern | Safe Aureon application |
| --- | --- | --- |
| [Palantir Ontology](https://www.palantir.com/platforms/ontology/) | A named platform structure makes the relationship between data, logic, action and governance legible. | Use an original HNC to Aureon OS to evidence-gated mission-blades proof map. Do not use Palantir terminology or visual treatment. |
| [Planet](https://www.planet.com/) | One concrete outcome sits above distinct product, industry and resource pathways. | Keep the shared core central, then show mission blades as individual lanes with buyer, present evidence, boundary and next proof. |
| [Schrodinger Platform](https://www.schrodinger.com/platform/) | A scientific platform proposition leads, while application routes stay distinct and supporting research remains inspectable. | Lead with Aureon's research-led evidence-system proposition and route visitors to Research, System and Use Cases rather than treating AI as the category. |
| [SandboxAQ Technical Research](https://pub.sandboxaq.com/) | Formal work is structured by record type, date and topic rather than blended with marketing explanation. | Preserve the separation between ORCID and DOI records, technical artefacts, and Substack explanation. Editorial artwork must not imply validation. |
| [Arc Institute](https://arcinstitute.org/) | Domain-native research visuals and strong hierarchy create seriousness without generic AI decoration. | Create only original HNC visual systems based on source, relation, feedback and state; avoid borrowed scientific or satellite imagery. |
| [Isomorphic Labs](https://www.isomorphiclabs.com/) | Research, technology, people and partnerships are deliberately separated, with scoped detail near the relevant narrative. | Place proof links and the exact limitation beside each Aureon use case. Do not publish grants, connections, figures or named relationships without an approved public source. |

## Design conclusion

The investor-ready direction is not maximal animation. It is a calm authored
system in which one understandable core creates multiple clearly bounded paths
to proof.

For a future V30 candidate, the highest-value information-design addition is
an original proof map:

1. HNC research framework.
2. Aureon OS evidence and control layer.
3. Mission-specific application blade.
4. Current evidence state and explicit limitation.
5. Next external proof gate.

That map must be built as a source-bound staged candidate, pass the existing
claims, accessibility, browser, visual and package controls, and receive
human visual acceptance before any release path is considered.
