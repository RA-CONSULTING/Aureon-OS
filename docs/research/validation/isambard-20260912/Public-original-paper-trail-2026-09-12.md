## What this changes about beta=1

The Zenodo PDF has six pages and 556,762 bytes. SHA-256: `dad45d3d999adc865a47b3eb2a737b6c9b618be833262f8914eb32a5f806d268`. Its MD5 matches Zenodo's published checksum, `1e96f8027b906d3de5d802d751bba26a`.

The recovered PDF differs byte-for-byte from the historical Git PDF. Text extraction differences include font and mathematical-symbol mappings. **Pages 2 and 6 were rendered and visually checked:** page 2 gives a condition involving both beta and alpha times gain; page 6 contains the 1.1 island/cliff statements. The selected parameter wording agrees with the Git copy. Full semantic identity is not claimed.

No SHA-256 match was found among the 180 indexed Git-native documents. This is one additional recovered file identity. The current file is verified against the current repository checksum; an independent archived capture proving the exact bytes available in November 2025 has not been obtained.

Gary's instruction supplies the authority to use **beta=1 as the intended reference** for the delayed-feedback experiment. The public archive strengthens the documentary trail but **does not establish the original reprint chronology**. It does not justify rewriting original files or changing beta in unrelated equations. The near-one April 7 appendix and the long-horizon Isambard results remain separate pieces of evidence.
