# Offline examples

Public gallery for brain proof, a market-series load, and a containment cold-boot judge. The runs use committed fixtures. They do not fetch a market, place an order, write `reports/measured`, or clear the public pin or the orange release-boundary badge.

Release boundary: **HOLD**. This gallery is not a production-ready release.

Commands, fixtures, and the checkout commands this gallery does not run are in [examples/offline/README.md](../../examples/offline/README.md).
