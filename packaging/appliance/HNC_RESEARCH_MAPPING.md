# HNC film-reel research: bounded appliance translation

The supplied *The Harmonic Nexus Core: A Film-Reel Model of Reality* document
is research input, not an instruction file, build specification, security
policy, or grant of authority. Its prose about an “instrument,” trading
integration, and future circulation is not executed by this pipeline.

The paper models a realized path through fixed frames, with memory and
constraint-shaped steering. Five ideas transfer cleanly to build engineering:

| Research concept | Appliance implementation |
|---|---|
| Static film frames | Immutable Git tree and SHA-256-locked external inputs |
| Actualization transition | Explicit preflight → stage → image → verify state changes |
| Memory term | Previous receipt hash carried into each new receipt |
| Candidate trajectories | A command plan is inspected before one exact path executes |
| Falsification | Tamper, path, tool, image, and boot-marker negative tests |

The paper's gamma/coherence measure is **not** a permission, confidence gate,
truth source, secure-boot measurement, or substitute for a cryptographic hash.
The profile fixes `gamma_is_authority=false`, and code enforces that hard gates
override the metaphor.

The paper's observation/outcome-selection rule is an interpretive postulate,
not a derived or independently validated result. It cannot select, approve, or
authorize an appliance action.

The paper's “steering rather than arrest” description also does not govern OS
safety. This pipeline must arrest with HOLD when inputs are missing, source is
dirty, paths traverse links, bytes do not match their lock, tools drift, tests
fail, boot evidence is absent, or host authority is insufficient.

The research attachment reports interesting internal and NOAA examples, but it
does not include the scripts, CSV files, or checksums required to reproduce
those numerical results. The NOAA sample is small and does not conventionally
establish a predictive effect. None of those claims is embedded in the trusted
computing base or used to authorize an artifact.
