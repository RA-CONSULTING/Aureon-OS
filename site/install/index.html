The smoke below does not read .env, leaves exchange keys unset, and keeps live trading off for that run. That is the smoke. It is not a statement that every launcher has trading off.

You need Python 3.11 or newer, Node.js 20 or newer, and npm. On Debian or Ubuntu, install python3-venv first. install.sh is a bash script. From Windows, run it with bash.

git clone https://github.com/RA-CONSULTING/Aureon-OS.git
cd Aureon-OS
./install.sh --smoke

What ./install.sh does

  • Creates .venv when it is missing, then installs the pinned requirements-plug.lock.
  • Runs npm ci --ignore-scripts --prefix frontend when the dashboard toolchain is absent.
  • Starts scripts/plug_and_play.py.
  • Does not read .env and does not copy .env.example into .env.
  • Sets AUREON_AUTONOMY_MODE=guarded, AUREON_LIVE_TRADING=0, and AUREON_LLM_OFFLINE=1.
  • Drops credential-shaped variables from the child environment.

If the stack starts, it binds loopback on that same machine:

  • Operator API: http://127.0.0.1:8790/
  • Public MCP: http://127.0.0.1:8077/mcp
  • Dashboard: http://127.0.0.1:5173/
  • Stack health: http://127.0.0.1:8787/

Those addresses are not a public service. Stop the stack with ./install.sh --stop.

What the smoke covers

./install.sh --smoke starts that same guarded stack, requests the local endpoints, and stops. A passing smoke checks the local process. It does not place an order. It is not deployment validation, and go-live stays HOLD. ./install.sh without --smoke starts the same guarded stack and leaves it running until ./install.sh --stop.

Other launchers can boot live

scripts/linux/aureon-up.sh can boot live trading when a full exchange key group is present in .env. When .venv/bin/python is missing, that script runs production/install.sh, which calls scripts/launch/aureon-master.sh (Windows: aureon-master.ps1 and aureon-master.bat). With autonomy left at the public default, that boot reports trading_mode=live (exchange keys present). Leave exchange keys unset. Strangers stay on ./install.sh --smoke. Go-live stays HOLD.
