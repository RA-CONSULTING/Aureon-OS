Live routes

The live routes are active. With exchange keys in .env, the launcher boots into live trading. There is no verified live track record.

The start-here command is the guarded smoke ./install.sh --smoke. It does not read .env, leaves exchange keys unset, and keeps live trading off for that run. That smoke is not a statement that every launcher has trading off.

scripts/linux/aureon-up.sh can boot live trading when a full exchange key group is present in .env. When .venv/bin/python is missing, that script runs production/install.sh, which calls scripts/launch/aureon-master.sh. With autonomy left at the public default, that boot reports trading_mode=live (exchange keys present). Go-live stays HOLD. That boot is not a deployment receipt.

Start here

  1. Clone github.com/RA-CONSULTING/Aureon-OS.
  2. Run ./install.sh --smoke. Leave exchange keys unset. Live trading stays off for that smoke.
  3. Read the MIT license before you copy or ship anything.
  4. Treat go-live as HOLD. A local smoke is not a deployment receipt.
