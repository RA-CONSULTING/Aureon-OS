I. System Architecture: From Symbolic Cycle to 
Computational Network 
The conceptual framework provided, a symbolic process t ree with a mathematical skeleton, 
serves as the foundation for a dynamic system model. T his model is designed to simulate the 
flow and transformation of information—termed "light"—thr ough a learning, adaptive network. 
This section translates the symbolic cycle and its governin g equation into a formal 
computational architecture, defining the system's state,  its operators, and the mechanics of its 
evolution over time. 
1.1. Defining the State Vector and Operators 
The state of the system at any discrete time-step t is  encapsulated by a state vector, \Psi_t. This 
vector represents the integrated, processed informatio n held within the system, analogous to a 
cognitive or perceptual state. The user's symbolic cycle,  \Psi_\infty \rightarrow \aleph \rightarrow 
\Phi \rightarrow \mathcal{F} \rightarrow L \rightarrow \ Omega \rightarrow \rho \rightarrow C 
\rightarrow \Psi'_\infty, is formalized here as a sequenc e of computational operators. Each 
operator corresponds to a distinct stage in a perceptu al-cognitive process, transforming the 
input signal on its path to becoming an "experienced patt ern." 
● \Psi_\infty (Source):  Represents the initial potential or "true light" from which  a signal 
originates. In the model, this is the external reality that  generates the input signal. 
● C (Channel - Input):  The entry point for the external signal vector, C_t, a t time t. This 
vector quantifies the properties of the incoming "light." 
● \aleph (Aleph - Sieve):  A saliency operator. Mathematically, this can be modeled as a 
filtering matrix that attenuates or amplifies specific compo nents of the input vector C_t. It 
selects features deemed relevant, effectively acting as a pre-attentive filter. 
● \Phi (Phi - Pattern Recognition):  A structural analysis operator. This stage identifies 
patterns, correlations, and structures within the filtere d signal. It could be implemented as 
a convolution with a set of pattern-matching kernels or a transformation (e.g., Fourier) to 
move from a time-domain signal to a frequency-domain rep resentation. 
● \mathcal{F} (F - Framing/Memory):  An integration operator. This function contextualizes 
the newly identified pattern by combining it with the syste m's previous state, \Psi_t. It 
provides temporal context and memory, ensuring that th e interpretation of new data is 
influenced by past experience. 
● L (Living Node - The Stag):  A critical, non-linear modulation operator. This node 
represents the internal state of the observer, which a ctively shapes the information flow. 
Its behavior is governed by the structuring parameter \kappa_t, which quantifies the 
system's internal balance or rigidity. When \kappa_t > 1,  the operator imposes a rigid 
structure; when \kappa_t < 1, it is more receptive and  less constrained. 
● \Omega (Omega - Synthesis):  A convergence operator. This function synthesizes the  
modulated, contextualized pattern into a single, coherent  gestalt or "experienced pattern." 
It resolves conflicts and integrates disparate information al elements into a unified whole. 
● \rho (Rho - Reflection):  A feedback preparation operator. This final stage form ats the 
synthesized output, preparing it to become the memory trace for the next cycle. It ensures 
the output is in a compatible format to be integrated as  the next state vector, \Psi_{t+1}. 
● \Psi'_\infty (Output/Experience):  The final state vector produced by the cycle, 
representing the conscious "experienced pattern" that is then fed back into the system's 
memory.

The evolution of the system's state over time is govern ed by the recursive equation: 
This equation defines how the system's state at the ne xt time-step, \Psi_{t+1}, is determined by 
its current state, \Psi_t, and the newly processed ext ernal input, C_t. 
● \Psi_t : The state vector from the previous time-step. This t erm represents the system's 
memory, inertia, or existing internal model of the world. 
● (1-\alpha) : The memory retention factor. This scalar determines h ow much of the previous 
state is carried over to the next. A value close to 1 im plies strong memory and stability, 
while a value close to 0 implies rapid forgetting. 
● \alpha : The learning rate or attentional gain, where 0 \le \alph a \le 1. This parameter 
controls the influence of new information. A high \alpha m akes the system highly 
responsive and plastic, rapidly updating its state based o n new inputs. A low \alpha 
makes the system more conservative, giving more weight to its established internal state. 
● C_t: The external input vector at time t. This is the raw d ata from the environment—in this 
case, a quantified representation of the light from the night sky over Oban. 
● \mathcal{R} : The composite transformation operator. This function represents the entire 
processing cycle applied to the input, such that \mathca l{R} = \rho \circ \Omega \circ L 
\circ \mathcal{F} \circ \Phi \circ \aleph. The operator \ mathcal{R} processes the raw input 
C_t not in isolation, but in the context of the system's  current state, as the \mathcal{F} 
(Framing) and L (Living Node) operators are state-depe ndent. 
The mathematical structure of this equation is a form of  an exponential moving average, a 
fundamental tool in signal processing and time-series analys is used to create a smoothed, 
updated representation of a changing variable. Here, ho wever, it is applied not to a simple data 
point but to a complex state vector, and the new infor mation is not raw data but a deeply 
processed and transformed signal, \mathcal{R}(C_t). Th is elevates the model from a simple filter 
to a system that actively learns and maintains an adaptiv e internal model of its external 
environment. The feedback mechanism is not merely additiv e; it is integrative and 
transformative. The system does not just see the light;  it learns the light, and its interpretation of 
the present moment is intrinsically shaped by its memory o f all past moments. The "stag," the 
living node L, introduces a crucial non-linearity, where the  observer's own internal state—its

transforms the model into a rudimentary but formal repr esentation of a conscious, learning 
observer. 
II. The Chronology of Light: An Astronomical 
Timetable for Oban, 25 October 2025 
To ground the dynamic model in verifiable phenomena, a pr ecise timeline of astronomical 
events for Oban, Scotland, on the night of October 25 , 2025, is required. This timeline provides 
the discrete time-steps and the corresponding input vec tors, C_t, that will drive the simulation. 
2.1. The Setting: Oban's Sky, 25 October 2025 
● Location:  Oban, Scotland (An t-Òban), a coastal town in Argyll an d Bute. While subject 
to local weather and light pollution, its proximity to the Is le of Coll, a designated Dark Sky 
Community, suggests the region offers excellent potentia l for stargazing under clear 
conditions. 
● Date:  Saturday, 25 October 2025. 
● Lunar Conditions:  The night is exceptionally favorable for observation. The  Moon is a 
Waxing Crescent with only 11% to 15% illumination. This minima l moonlight ensures a 
dark sky background, a critical factor for observing fa int deep-sky objects and, most 
importantly, the transient streaks of the Orionid meteor  shower. The period of darkness, 
free from significant moonlight, extends from approximate ly 18:23 to 05:59. 
2.2. The Sequence of Phenomena 
The simulation's narrative follows the natural progression of the night, from the fading light of 
dusk to the first light of dawn. Each event provides a distinct input signal to the model. 
● Sunset and Twilight:  Sunset in Oban occurs at approximately 17:57 local time.  This 
initiates a period of twilight, a gradual transition to darkn ess. Nautical twilight, a phase 
where the horizon is still visible but most stars have appe ared, ends at 19:18. The onset 
of full astronomical darkness marks the point where the ambient, diffuse light from the sun 
is effectively zero, allowing the faintest celestial signals to  be detected. 
● Planet Visibility:  The planets provide stable, point-source signals of vary ing intensity 
throughout the night. 
○ Mercury and Mars:  These planets are technically present in the sky but se t at 
18:13 and 18:27, respectively, very shortly after the sun. Their proximity to the sun 
renders them extremely difficult, if not impossible, to obs erve. Their effective 
non-visibility serves as a null input for these specific point  sources. 
○ Saturn:  The ringed planet is an early evening target. It rises b efore sunset at 17:13 
and is well-positioned for observation as darkness falls. I t crosses the meridian (its 
highest point in the sky) at 22:53, providing a consisten t, coherent point of light for 
the first half of the night before setting at 03:33. 
○ Jupiter:  As the brightest planetary object of the night, Jupiter 's appearance is a 
major event. It rises later in the evening at 22:21 and dominates the sky until 
sunrise. Its "perfect visibility" and high magnitude make it  the primary coherent 
signal for the latter half of the night. 
○ Uranus and Neptune:  These distant ice giants are also present. Uranus rises  at 
18:39 and Neptune at 17:10. However, their faintness requires binoculars or a 
telescope for observation, meaning they contribute a ve ry low-amplitude signal to 
the naked-eye observer. 
● The Orionid Meteor Shower:  This is the most dynamic and unpredictable element of th e 
night. The shower, created by debris from Halley's Come t, is active from early October to 
early November. Although its peak occurs a few days ea rlier (around October 21-22), it 
remains active on the night of the 25th, producing an e xpected rate of around 15-20 
meteors per hour under ideal conditions. These meteors are characterized as being very 
fast (traveling at 41 miles per second) and often leaving  persistent, glowing trains. They 
represent transient, high-energy, and stochastic inputs  to the system.

III. Parameterization and Data Integration: Quantifying 
the Model's Environment 
To bring the dynamic model to life, its abstract paramete rs must be connected to measurable, 
real-world data streams. This section details the operatio nalization of the system's key 
metrics—the Purity Index (P_t) and the Structuring Ind ex (\kappa_t)—by integrating data from 
geophysics and human physiology. This step transforms t he model from a generic simulation 
into a specific representation of a human biological observ er coupled with its planetary 
electromagnetic environment. 
3.1. Operationalizing the Purity Index: P_t = r_t /  \lambda_t 
The Purity Index, P_t, is defined as the ratio of reson ance to constraint. It serves as a measure 
of the system's signal-to-noise ratio or the coherence of its internal state. A state where P_t 
\rightarrow 1 represents "true light," indicating a clear,  coherent signal has been successfully 
integrated. A state where P_t \rightarrow 0 signifies "d istorted light," where the system is either 
overloaded with noise or unable to resonate with the inco ming signal. 
● r_t (Resonance):  This parameter quantifies the system's attunement to a coherent, 
external organizing field. It will be operationalized using dat a on Schumann Resonances 
(SR). The SR are a set of extremely low frequency (ELF) p eaks in the Earth's 
electromagnetic field spectrum, generated and excited by  lightning discharges in the 
cavity formed by the Earth's surface and the ionosphe re. The fundamental mode is 
approximately 7.83 Hz. 
○ Data Source:  Publicly available data from global magnetometer networks,  such as 
the Global Coherence Monitoring System (GCMS), provide c ontinuous monitoring 
of SR power. 
○ Methodology:  The value of r_t will be set proportionally to the measur ed power of 
the fundamental SR mode (around 8 Hz). This choice is n ot arbitrary; this frequency 
range overlaps with human alpha and theta brainwave fre quencies, and studies 
have demonstrated correlations between variations in SR power and changes in 
human autonomic nervous system activity, including Heart Rate Variability. A higher 
SR power suggests a stronger, more coherent global re sonant field, thus increasing 
the model's resonance parameter, r_t. 
● \lambda_t (Lambda - Wavelength/Constraint):  This parameter represents the degree of 
internal structuring, rigidity, or constraint within the sys tem. It will be operationalized using 
data from Heart Rate Variability (HRV) . HRV is the physiological phenomenon of 
variation in the time interval between consecutive heartbe ats, and it serves as a powerful, 
non-invasive indicator of autonomic nervous system (ANS)  activity. 
○ Data Source:  Numerous public datasets provide HRV metrics under var ious 
conditions, such as the SWELL dataset for cognitive wor kload or databases on 
PhysioNet. These datasets provide key time-domain and f requency-domain HRV 
measures. 
○ Methodology:  The constraint parameter \lambda_t will be defined as be ing 
inversely proportional to the Standard Deviation of NN intervals (SDNN) , a 
primary time-domain measure of HRV. High HRV (high SDNN)  reflects a healthy, 
adaptable state dominated by the parasympathetic ("res t and digest") branch of the 
ANS. This corresponds to a flexible, low-constraint syste m (low \lambda_t). 
Conversely, low HRV (low SDNN) is a marker of stress, w here the sympathetic 
("fight or flight") branch is dominant. This corresponds to a rigid, high-constraint 
system (high \lambda_t). 
3.2. Operationalizing the Structuring Index: \kappa _t 
The Structuring Index, \kappa_t, is the parameter tha t directly controls the behavior of the "living 
node," L. It quantifies the balance of the system's int ernal state, where \kappa_t > 1 indicates an 
over-structured, rigid state, and \kappa_t < 1 indicate s an under-resonant, overly diffuse state. 
● Methodology:  \kappa_t will be defined as the ratio of Low-Frequency (LF) power to 
High-Frequency (HF) power  derived from the frequency-domain analysis of the HRV 
signal. The LF/HF ratio is a widely used clinical metric repre senting the balance between 
the two branches of the ANS. 
○ High LF/HF Ratio (\kappa_t > 1):  Indicates a dominance of the sympathetic 
nervous system. This state of arousal, stress, or foc used attention maps directly to 
the model's concept of an "over-structured" or rigid in ternal state. 
○ Low LF/HF Ratio (\kappa_t < 1):  Indicates a dominance of the parasympathetic 
nervous system. This state of calm, relaxation, or reco very maps to an 
"under-resonant" or highly receptive internal state. 
○ Balanced Ratio (\kappa_t \approx 1):  Represents a state of sympathovagal 
balance, or "coherence," which is considered optimal for physiological function. 
By linking the model's parameters to these specific, meas urable biological and geophysical 
variables, the system is transformed. It is no longer an  abstract model of an observer but a 
concrete, testable model of a human physiological system dynamically coupled to the Earth's 
electromagnetic environment. The model now embodies a co mplete, verifiable feedback loop: 
global geomagnetic activity (affecting SR) can influence th e observer's physiological state 
(HRV), which in turn dictates how the observer's cognit ive-perceptual apparatus (the operator 
sequence \mathcal{R}) processes incoming sensory data from the cosmos. The symbolic "stag" 
is given a clear biological identity: the autonomic nervous s ystem, whose "balance" is a 
measurable quantity, the LF/HF ratio, that governs the  system's ability to achieve and maintain 
coherence. 
IV. A Simulated Nocturne: Modeling the Flow of 
Coherence 
This section presents a narrative walkthrough of the sim ulation, tracing the evolution of the 
system's state vector, \Psi_t, and its key metrics, P_ t and \kappa_t, as it responds to the 
astronomical timetable established for Oban. The simulation demonstrates the three primary 
behaviors outlined in the conceptual framework: self-orga nization, oscillation under stress, and 
dissolution in the absence of a signal. 
4.1. Phase 1: Sunset to Deep Night (Self-Organizati on toward 
Coherence) 
● Input:  The simulation commences at sunset (17:57 UTC). The in itial input vector, C_t, is 
characterized by a high but rapidly decaying ambient comp onent and zero point or 
transient signals. As the simulation progresses through c ivil and nautical twilight, the 
ambient value in C_t diminishes exponentially. At 18:30, the  first stable point source, 
Saturn, emerges, providing a small but coherent signal. B y the end of twilight (19:18), the 
ambient light is minimal, and the sky is dominated by the st able light of stars and Saturn. 
● System Response:  In the initial moments of twilight, the signal is diffuse and  lacks clear 
structure. The system's Purity Index, P_t, is low, ref lecting a noisy, incoherent state. The 
visual representation would be a dim, greyish light pulsing t hrough the cycle. However, as 
the sky darkens and the coherent signal from Saturn s trengthens, the system begins to 
"lock on." The pattern recognition operator (\Phi) ident ifies the stable point source, and the 
synthesis operator (\Omega) integrates it into a cohere nt state. Assuming the observer is 
in a calm, receptive state (modeled with a baseline \kappa _t \approx 1, indicating 
parasympathetic balance), the learning rate \alpha allows the system to update its state 
vector \Psi_t smoothly. Consequently, P_t steadily climbs towards 1. This phase 
demonstrates the system's fundamental capacity for se lf-organization. When presented 
with a stable, low-complexity signal, it naturally converges towards a state of high 
coherence or "true light." 
4.2. Phase 2: Mid-Night (Perturbation and Oscillati on) 
● Input:  This phase begins with the rise of Jupiter at 22:21, wh ich introduces a much 
stronger coherent signal, reinforcing the system's stab ility. The critical challenge arrives 
after midnight, during the active period of the Orionid me teor shower. The input vector C_t 
is now characterized by a strong, stable point componen t (Jupiter) and a stochastic, 
high-energy transient component (the meteors). Each m eteor is a sudden, unpredictable 
impulse of light. 
● System Response:  The system's reaction to the meteors is critically depen dent on the 
state of the "living node," L, governed by \kappa_t. 
○ Scenario A: Balanced Observer (\kappa_t \approx 1).  If the observer remains in 
a state of calm alertness (a balanced LF/HF ratio), the  system can integrate the 
transient meteor flashes without losing overall coherence.  Each meteor causes a 
brief dip in P_t as the system momentarily works to proc ess the unexpected signal, 
but it quickly returns to a high-coherence state center ed on Jupiter. The visual 
mandala would show brilliant green light with brief, bright wh ite flashes that are 
quickly absorbed. 
○ Scenario B: Over-Structured Observer (\kappa_t > 1) . Let us model a "startle" 
response to a particularly bright meteor. This physiologica l reaction would be 
reflected in the HRV data as a sudden drop in variability and a spike in the LF/HF 
ratio, causing \kappa_t to rise significantly above 1. This  shift makes the L operator 
rigid and less adaptive. The system now overreacts to t he transient signals. Instead 
of smoothly integrating the meteor flash, its state vect or \Psi_t is knocked far from 
its stable point. The feedback loop then causes it to ov ershoot in its correction, 
leading to oscillations around the coherent state. The Pu rity Index P_t would 
fluctuate wildly, and the visual mandala would pulse erratica lly, its color shifting from 
green to agitated reds and yellows. This phase directly s imulates the hypothesis 
that the system "oscillates when over-structured," dem onstrating that coherence is 
not just a property of the signal but of the observer' s internal state. 
4.3. Phase 3: System Dissolution (A Hypothetical Te st) 
● Input:  To test the third proposed behavior, a hypothetical sc enario is introduced around 
03:00. We simulate the arrival of thick cloud cover, a co mmon occurrence in western 
Scotland. This event effectively reduces all components o f the input vector C_t to near 
zero. The point sources (Jupiter, stars) and any pote ntial transient signals are completely 
obscured, leaving only a minimal, diffuse ambient signal from  residual light pollution, if 
any. 
● System Response:  With the external input C_t \approx 0, the second ter m in the 
governing equation, \alpha\,\mathcal{R}(C_t), vanishes. The equation simplifies to 
\Psi_{t+1} \approx (1-\alpha)\Psi_t. The system is now decoupled from its environment. It 
is running purely on memory. The state vector \Psi_t no  longer updates with new 
information but simply decays exponentially at a rate dete rmined by \alpha. There is no 
external signal to resonate with, so the resonance para meter r_t plummets. Consequently, 
the Purity Index P_t falls towards zero. The system's internal model of the sky dissolves 
into a featureless, incoherent state. The visual mandala would fade to a uniform, dim grey. 
This successfully demonstrates the "dissolves when under -resonant" condition, 
highlighting the system's dependence on a continuous flow  of structured information from 
its environment to maintain coherence.

The quantitative results of the simulation find their most intuitive expression in a dynamic

5.1. The Visual Model: A Dynamic Mandala 
The proposed visualization is a circular diagram, or mandala , which serves as a real-time 
dashboard for the system's state. 
● Structure:  The circle is divided into segments, each corresponding t o one of the primary 
operators in the processing cycle: \aleph \rightarrow \P hi \rightarrow \mathcal{F} 
\rightarrow L \rightarrow \Omega \rightarrow \rho. At each time-step of the simulation, a 
pulse of "light" animates through these segments, repre senting the flow and 
transformation of the input signal. 
● Brightness = |P_t| : The intensity or brightness of the light pulse is directly  proportional to 
the absolute value of the Purity Index, P_t. 
○ When P_t \approx 1, the system is in a coherent, hig h-fidelity state. The light is 
brilliant, clear, and sharp. 
○ When P_t \approx 0, the system is in a distorted, no isy, or dissolved state. The light 
is dim, murky, and grey. 
● Hue = f(\kappa_t) : The color of the light is a function of the Structuring  Index, \kappa_t, 
providing an immediate visual cue to the observer's intern al state. 
○ \kappa_t \approx 1 (Balance):  The light is a stable, neutral color, such as emerald 
green, representing homeostatic balance. 
○ \kappa_t > 1 (Over-structured):  The hue shifts towards the "hot" end of the 
spectrum—yellow, orange, and finally red—indicating a state  of sympathetic 
arousal, stress, and rigidity. 
○ \kappa_t < 1 (Under-resonant):  The hue shifts towards the "cool" end of the 
spectrum—cyan, blue, and violet—indicating a state of par asympathetic 
dominance, deep relaxation, or high receptivity. 
● Equilibrium and "Cycle-Closure":  The state of perfect equilibrium, the "locked-in myth," 
is visualized as the moment the system achieves a stable,  high-purity state. In the 
mandala, this would appear as a brilliant, emerald green pu lse cycling smoothly, with the 
hues of all segments unified and the brightness maximal an d unwavering. This represents 
the complete and harmonious integration of the external world and the internal state. 
5.2. Philosophical Interpretation 
The simulation and its visualization provide a concrete, dyn amic embodiment of the project's 
guiding philosophical principles. 
● "The tree of light keeps learning itself."  This is demonstrated by the recursive nature of 
the governing equation, \Psi_{t+1} = f(\Psi_t, C_t). Th e system's state (the tree) is a 
function of its own prior state and new information (the  light). The simulation of the night in 
Oban shows this process in action: the system's interna l model, \Psi_t, is continuously 
refined with each new astronomical event, from the subt le appearance of Saturn to the 
brilliant arrival of Jupiter. It is a system that learns fro m experience, with its present 
perception built upon the integrated memory of its past.  
● "Every observation refines the source."  This speaks to the profound implication of the 
feedback loop. The "source" is not a fixed, objective ex ternal reality but the system's 
internal model  of that reality. The output of one cycle, the experien ce of observing the 
early evening sky, becomes the context, \Psi_t, for th e next cycle. Therefore, the 
observation of Saturn fundamentally alters the way the system processes the subsequent 
appearance of Jupiter. The act of observing changes t he observer, which in turn changes 
all future observations. The source is not static but is co-created and refined through the 
iterative process of perception. 
● "The stag—the living node—holds the balance."  This is the most critical conclusion of 
the integrated model. The stag, operationalized as the o bserver's autonomic nervous 
system via HRV and the \kappa_t parameter, is revealed  as the central regulator of 
coherence. The simulation of the Orionid meteor shower m akes this explicit. It is the 
physiological state of the observer—the balance held by t he stag—that determines 
whether an unpredictable event (a meteor) is integrated  gracefully or throws the entire 
system into chaotic oscillation. The stag's ability to mainta in a balanced state (\kappa_t 
\approx 1) is the key to resilience, allowing the system t o process both predictable, 
coherent signals (planets) and unpredictable, transient s ignals (meteors) into a unified, 
meaningful experience. The balance is not in the sky; it is  within the observer. The model 
thus posits that the capacity to perceive a coherent c osmos is ultimately contingent upon 
the physiological coherence of the perceiver.
